# ديوان بن شرعان

موقع عربي مستقل وخفيف، بهوية عاجية وفحمية وذهبية. لا يحتاج حسابًا أو قاعدة بيانات أو تثبيت مكتبات. يحتاج Node.js إصدار 20 أو أحدث لتشغيل المعاينة وإعادة توليد الصفحات. راجع [تعليمات GitHub والفحص](README-GitHub.md) لتجهيز المستودع وضبط رابط الاستضافة.

## التشغيل على Windows

1. افتح `Start-Diwan.cmd`.
2. افتح العنوان `http://127.0.0.1:8794` في المتصفح.
3. لإيقاف التشغيل أغلق نافذة التشغيل، أو اضغط Ctrl+C.

المعاينة الحالية تعمل على جهازك. المجلد `dist` هو الموقع الجاهز للاستضافة، ويتضمن المصدر الأصلي وصور البطاقات.

## تعديل القصائد

1. احتفظ بنسخة احتياطية من `dist/data.json`.
2. عدّل العنوان أو الأبيات أو خيار `featured` في ملف البيانات، أو اطلب التعديل في هذه المحادثة.
3. افتح `Build-Diwan.cmd` لتوليد الصفحات، ثم أعد تحميل المتصفح.

أُزيلت صفحة إدارة المحتوى بطلب صاحب المشروع. لا تعتمد نصًا مشكوكًا فيه قبل مقابلته بصورة المصدر.

## بنية سجل القصيدة

- `id`: معرف ثابت من أحرف إنجليزية وأرقام وشرطة؛ يحدد رابط الصفحة.
- `title`, `titleOrigin`: العنوان ومصدره؛ عناوين النسخة الأولى من مطلع النص.
- `verses`: مصفوفة أبيات؛ كل بيت مصفوفة من الشطرين بترتيبهما.
- `text`: نسخة نصية للأبيات؛ `verses` هي المرجع لتوليد الصفحات.
- `keywords`: الكلمات المفتاحية.
- `status`, `issues`: حالة المراجعة وملاحظاتها.
- `source.page`, `source.region`: صفحة الملف ورقم البطاقة.
- `featured`: إظهار النص ضمن مختارات الرئيسية.
- `attribution`: تنبيه النسبة عندما تكون غير محسومة.

عند استيراد مصدر جديد أضف صورته إلى `dist/sources` وحدّث طريقة عرض صور المصدر في `build.mjs` إذا تجاوزت أرقام البطاقات الحالية. تعديل البيانات لا يحتاج تعديل تصميم الموقع.

## ملفات المشروع

- `build.mjs`: مولد الصفحات والفهرس وبيانات SEO.
- `server.mjs`: خادم محلي يعمل على 127.0.0.1 فقط.
- `dist/style.css` و`dist/identity.css`: التصميم العام والهوية الأدبية.
- `dist/app.js`: البحث والنسخ والمشاركة وأدوات القراءة.
- `dist/data.json`: جميع السجلات الـ24، بإجمالي 217 بيتًا.
- `dist/source.pdf` و`dist/sources`: المصدر وصور البطاقات.

## حدود النسخة

- استيراد كامل المادة الظاهرة في الملف المرفق، وليس ادعاء أن الملف يمثل جميع إنتاج الشاعر.
- روجعت المواضع الست الأصلية مع صاحب المشروع. أضيفت p23 من فيديو X أرسله صاحب المشروع مع تصحيحاته، وp24 من نصه المباشر في مدح أخي الشاعر عبدالله. أكد صاحب المشروع كلمة «لمروج» في البيت الثاني من p23.
- توقيع «بارود الشهم» ظاهر في بطاقتين؛ أكد صاحب المشروع أنه كان لقب الشاعر على تويتر (X حاليًا).
- خط القراءة يستخدم الخطوط العربية المتاحة على الجهاز؛ يمكن إضافة خط ويب مرخص لاحقًا.
- Open Graph يتضمن عنوانًا ووصفًا ورابطًا لكل قصيدة، دون صورة مشاركة مصطنعة.
- عند النقل إلى نطاق آخر اضبط متغيري البيئة `SITE_URL` و`BASE_PATH` ثم أعد التوليد، وفق تعليمات `README-GitHub.md`.
- تم تسجيل الموقع في Sites بإعداد وصول خاص، لكن الرفع لم يكتمل بسبب قيود تنفيذ خطوة الرفع في الجلسة. رابط Sites المتوقع ليس دليلًا على أن الموقع منشور. المعاينة المحلية تعمل.
- تحديث النسخة المستضافة يحتاج إعادة نشر ملفات `dist` بعد التوليد.

أُزيلت صفحة الشاعر وخاصية التصنيف وصفحة إدارة المحتوى بالكامل بطلب صاحب المشروع.


في نسخة GitHub يتولد HTML عند التشغيل أو البناء. استخدم npm start أو Start-Diwan.cmd لبدء المعاينة، أو npm run build لتوليد dist. النسخة الكاملة قبل الرفع موجودة في site-source.zip.
