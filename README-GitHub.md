# تجهيز ديوان بن شرعان لـ GitHub

## التشغيل والفحص

تحتاج Node.js إصدار 20 أو أحدث. داخل مجلد المشروع، دون تثبيت مكتبات إضافية:

```sh
npm start
npm run build
npm test
```

المعاينة: http://127.0.0.1:8794/ . على Windows يمكن فتح `Start-Diwan.cmd` و`Build-Diwan.cmd`. لا تعتمد ملفات التشغيل على مسار جهاز المطور. لإيقاف الخادم اضغط Ctrl+C.

يفحص `npm test` سجلات القصائد و27 صفحة وروابطها، وحفظ جميع الأبيات وترتيبها، ومختارات الرئيسية p04 ثم p05 ثم p14، ومحاكاة النشر داخل مسار مستودع. يعيد في النهاية بناء الموقع حسب إعدادات التشغيل الحالية.

## ما ترفعه إلى المستودع

ارفع محتويات مجلد المشروع باعتبارها جذر المستودع، بما فيها ملفات المصدر و`dist` و`.gitignore`. لا يحتاج المشروع `npm install`.

يستبعد `.gitignore` إعدادات الخدمة السابقة والملفات البيئية والسجلات المؤقتة. النسخة المضغوطة المعدة للرفع لا تتضمن هذه الملفات. لم يُنفذ رفع إلى GitHub ضمن هذه المراجعة.

## إعداد عنوان الاستضافة

رفع المصدر إلى GitHub منفصل عن نشر الموقع. `dist` هو المجلد الجاهز للاستضافة. اضبط القيم الحقيقية قبل النشر:

- `SITE_URL`: أصل النطاق فقط، مثل `https://YOUR_NAME.github.io`.
- `BASE_PATH`: مسار المستودع مثل `/YOUR_REPOSITORY`؛ فارغ عند الاستضافة في جذر النطاق.

مثال PowerShell داخل مجلد المشروع:

```powershell
$env:SITE_URL = 'https://YOUR_NAME.github.io'
$env:BASE_PATH = '/YOUR_REPOSITORY'
npm run build
```

تتولد روابط الأصول والفهرس والقصائد والبحث وSEO وفق هذين المتغيرين، دون تعديل الشفرة. انشر محتويات `dist` بعد ضبطهما.

للعودة إلى المعاينة المحلية:

```powershell
$env:SITE_URL = 'http://127.0.0.1:8794'
$env:BASE_PATH = ''
npm run build
npm start
```

النسخة الافتراضية تستخدم عنوان المعاينة المحلي؛ يجب ضبط النطاق الحقيقي قبل النشر.

## صيانة البيانات

`verses` مصفوفة أبيات؛ كل بيت مصفوفة شطرين. اجعل `text` مطابقًا لها بوصل الشطرين بـ ` | ` ووصل الأبيات بسطر جديد. يرفض الفحص البيت الناقص والمعرف المكرر أو غير الآمن قبل توليد الصفحات. لا تُصحح الشعر دون اعتماد صاحب المشروع.

المصادر: PDF عبر `source.page` و`source.region`؛ فيديو عبر `source.type: "x"` و`url` و`postId`؛ نص مقدم عبر `source.type: "user"` و`receivedAt`. يسجل `reviewHistory` التصحيحات، وتظهر `readingNotes` في تفاصيل المصدر. `dedication` يوضح المناسبة، و`featuredOrder` ترتيب المختارات.

مصدر p23 وp24 مستقل عن PDF. لا تزال كلمة «لرموج» في p23 تنتظر التأكيد. الفيديو يحتاج اتصالًا بـ X، ويبقى رابط المشاهدة الأصلي ظاهرًا إذا تعذر التضمين.

`config.mjs` لإعدادات النشر، و`validate.mjs` للتحقق من البيانات، و`test.mjs` للفحص الآلي. خادم المعاينة يعمل من أي مجلد تشغيل.


في المستودع تُرفع الشفرة والبيانات والصور الأصلية، وتتولد صفحات HTML آليًا عند npm start أو npm run build. لم تُرفع مجلدات HTML المولدة كملفات منفصلة؛ النسخة الكاملة الجاهزة محفوظة في site-source.zip.
